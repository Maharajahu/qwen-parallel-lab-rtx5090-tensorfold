# Credits and source origins

## Starting point: TensorFold

These experiments start with [TensorFold](https://github.com/ashhart/TensorFold), created by [Ash (@ashhart)](https://github.com/ashhart) and its contributors. Ash's demonstrations of parallel local generation inspired the first fanout experiment.

Both native patches apply to upstream commit [`6e9af930261a88bb28ac0bfb157ce8e57e9eea07`](https://github.com/ashhart/TensorFold/tree/6e9af930261a88bb28ac0bfb157ce8e57e9eea07), version 1.2.6. The inference engine, model support and existing kernels are upstream work. See TensorFold's [own contributor credits](https://github.com/ashhart/TensorFold/blob/6e9af930261a88bb28ac0bfb157ce8e57e9eea07/docs/credits.md) for the authors of its individual components.

The exact local changes are available as two independent patches, with source hashes and reconstruction notes in [engine-manifest.json](engine-manifest.json). Upstream licenses and attribution are preserved in [licenses/TensorFold](licenses/TensorFold).

## Agent, model and drafter

- **Oh My Pi:** [@can1357, Stencil Labs and contributors](https://github.com/can1357/oh-my-pi), for the coding-agent terminal, conversation handling and extension system. The package uses 18.18.8, commit [`679691a78141de0dd6ba1b7a5d5c1b1d7d967a63`](https://github.com/can1357/oh-my-pi/commit/679691a78141de0dd6ba1b7a5d5c1b1d7d967a63).
- **Base model:** the [Qwen team / Alibaba](https://huggingface.co/Qwen/Qwen3.8-27B), for Qwen3.8-27B.
- **NVFP4 checkpoint:** [NVIDIA](https://huggingface.co/nvidia/Qwen3.8-27B-NVFP4), for the quantized checkpoint. The tested revision is [`482ca0f3832238542f8f5295dde86b5f22711d80`](https://huggingface.co/nvidia/Qwen3.8-27B-NVFP4/tree/482ca0f3832238542f8f5295dde86b5f22711d80).
- **DFlash 2:** [Inco AI](https://inco.ai/blog/dflash2/), for the speculative draft model. The experiment downloads the [Z Lab mirror](https://huggingface.co/z-lab/Qwen3.8-27B-DFlash2) at revision [`50307d4c4cde6860d4eee73e2547cd786fe8e8a4`](https://huggingface.co/z-lab/Qwen3.8-27B-DFlash2/tree/50307d4c4cde6860d4eee73e2547cd786fe8e8a4).
- **Original DFlash research:** Jian Chen, Yesheng Liang and Zhijian Liu, for *DFlash: Block Diffusion for Flash Speculative Decoding*; see the [project and paper references](https://github.com/z-lab/dflash).

The models retain their publishers' terms. The public setup downloads the pinned files separately and verifies their hashes.

## Scene and validation tools

[Three.js and its contributors](https://github.com/mrdoob/three.js/tree/r180) provide the 3D rendering library used by the scene host. [Playwright](https://github.com/microsoft/playwright) supplies browser automation, and [ESLint](https://github.com/eslint/eslint) supplies static JavaScript checks. Their upstream licenses remain applicable.

The native build uses [Zig](https://ziglang.org/) and [NVIDIA CUDA](https://developer.nvidia.com/cuda-toolkit). These tools are installed separately.

## Work in this repository

[Maharajahu](https://github.com/Maharajahu) maintains the experimental patches, OMP harnesses, portable Windows setup, benchmark evidence and recordings here. The scene component code in the demonstrations was generated by the local model, using the supplied host, primitives and task contracts.

The local additions include the seven-node draft-head experiment, the shared-context and synchronized-branch experiment, and their user-facing integrations. The OMP fanout integration was independently implemented from the observed workflow; its provenance and limitations are documented in [measurements](docs/measurements.md).
