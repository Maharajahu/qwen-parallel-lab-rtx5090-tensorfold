# Twelve-component Lantern Citadel workload

Install the repository requirements, the `experimental12` native variant, and the scene dependencies listed in the root README. The prepared workspace contains the plan, component contract, assembler and browser validator. Component code must be generated by the local model.

From the repository root:

```powershell
.\variants\experimental12\Start-Agent.cmd -WorkingDirectory "$PWD\variants\experimental12\demo\lantern-citadel"
```

Enter:

> Build the scene in TASK.md with twelve synchronized branches. Integrate the files and verify the result in the browser. Use English throughout; finish with a two-line summary.

The task requires one synchronized group of twelve distinct components. Its per-task completion budgets total 48,896 tokens; each includes LOW reasoning with a 2,048-token cap. Proposals return as saved files. Native memory admission may reject a group on a different GPU or memory state; the task requires reporting that failure without silently splitting it into waves.

Open the generated `lantern-citadel/site/index.html` to inspect the result. Browser checks cover twelve initialized components, render readiness, pause/resume, Lumos, orbit, zoom, reset and browser errors. Passing these functional checks is not a photorealistic-quality claim.

For another generation, use a fresh clone with the same setup. The demo host imports the repository's existing fanout geometry SDK and verified Three.js assets; preserve that directory structure.
